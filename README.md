# HydroBulletin — тиждень 1

Початкова версія магістерського інженерного проєкту з автоматизації обробки оперативних гідрологічних даних.

## Що вже працює

- читання локального демонстраційного файла у UTF-8;
- відбір записів 31 гідрологічного поста Львівської області;
- декодування групи `1HHHH` — рівень у строк 08:00;
- декодування групи `2HHHK` — добова зміна рівня;
- декодування групи `3HHHH` — рівень о 20:00 попередньої доби;
- коректна обробка від’ємних рівнів і `NIL`;
- нормалізована модель `HydroObservation` зі статусом якості;
- підготовча архітектура джерел даних: локальний файл зараз, онлайн-джерело на тижні 2;
- початкова SQLite-схема архіву (`stations`, `imports`, `observations`);
- безпечний шаблон `.env.example` без справжніх доступів;
- автоматизовані тести декодера, локального джерела й архіву.

## Запуск демонстрації

```bash
python main.py
```

Запуск із підготовкою порожнього SQLite-архіву:

```bash
python main.py --init-archive
```

Тести:

```bash
python -m unittest discover -s tests -v
```

У Windows також можна використати:

- `run_demo.bat`;
- `run_archive_demo.bat`;
- `run_tests.bat`.
