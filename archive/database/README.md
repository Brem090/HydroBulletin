# SQLite-архів

Створення або оновлення схеми:

```bash
python main.py --init-archive
```

Робоча база `hydro_archive.sqlite` створюється автоматично під час першого
імпорту та не додається до Git.

Основні таблиці:

- `stations` — довідник постів і потрібних метеостанцій;
- `imports` — початкові файли, їхні SHA-256 та складені ключі джерела;
- `observations` — нормалізовані параметри, QC-прапорці й пояснення;
- `corrections` — контрольовані ручні правки без зміни оригіналу;
- `reference_extremes` — багаторічні максимальні, середні й мінімальні рівні;
- `products` — сформовані Word-бюлетені, карта та графіки;
- `product_observations` — зв’язки продуктів із використаними значеннями;
- `schema_meta` — версія схеми.

Поточна версія схеми — 4. Під час відкриття попередня версія автоматично
оновлюється зі збереженням наявних ідентифікаторів і вимірювань.
