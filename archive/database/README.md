# SQLite-архів

Створення або оновлення схеми:

```bash
python main.py --init-archive
```

Робоча база `hydro_archive.sqlite` створюється автоматично під час першого імпорту та не додається до Git.

Основні таблиці:

- `stations` — довідник постів і потрібних метеостанцій;
- `imports` — початкові файли, їхні SHA-256 та складені ключі джерела;
- `observations` — нормалізовані параметри, QC-прапорці й пояснення;
- `products` — сформовані Word-бюлетені;
- `product_observations` — зв’язки продуктів із використаними значеннями;
- `schema_meta` — версія схеми.

Схема v3 автоматично оновлює базу тижня 2 зі збереженням наявних
ідентифікаторів і вимірювань.
