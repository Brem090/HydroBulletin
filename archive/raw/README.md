# Raw-архів

Кожне успішно отримане повідомлення зберігається у UTF-8 без зміни його тексту:

```text
raw/
└── 2026/
    └── 07/
        ├── 2026-07-12_ZRUR52.txt
        ├── 2026-07-12_ZRUR53.txt
        └── 2026-07-12_ZRUR71.txt
```

Однаковий вміст повторно не записується. Якщо за ту саму дату й тип надійшов змінений файл, він отримує суфікс `_2`, `_3` тощо, а попередня версія не перезаписується.
