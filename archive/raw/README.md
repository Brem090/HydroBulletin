# raw

Каталог призначений для збереження оригінальних гідрологічних повідомлень без будь-яких змін. Далі буде реалізовано автоматичне архівування повідомлень із формуванням структури:

рік/
└── місяць/
    └── дата_тип.txt

де:
• рік — рік спостереження;
• місяць — назва або номер місяця;
• дата — дата повідомлення;
• тип — тип отриманого повідомлення (наприклад ZRUR52 або ZRUR71).
