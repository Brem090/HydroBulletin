# Локальний архів HydroBulletin

- `raw/` зберігає отримані кодовані повідомлення без зміни їхнього тексту;
- `database/` містить локальну SQLite-базу з журналом імпортів і нормалізованими часовими вимірюваннями.

Обидва шари пов’язані полем `source_file`: від рядка SQLite можна перейти до початкового raw-файла.

Реальні raw-файли та робочі SQLite-бази не завантажуються до публічного GitHub.
