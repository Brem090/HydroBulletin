# Локальний архів HydroBulletin

- `raw/` — тут на другому тижні зберігатимуться незмінені файли, отримані з віддаленого джерела або імпортовані локально.
- `database/` — тут створюється `hydro_archive.sqlite` із довідником постів, журналом імпортів і структурованими спостереженнями.

Файли реального робочого архіву не повинні завантажуватися до публічного GitHub.
