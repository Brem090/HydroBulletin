# Перше демо HydroBulletin — до 10 хвилин

## 1. Короткий вступ — 1 хвилина

Мета тижня 2 — показати не готовий інтерфейс, а надійний наскрізний шлях даних: джерело → raw-копія → декодування → SQLite → читабельний результат.

## 2. Структура проєкту — 1 хвилина

Показати модулі `sources.py`, `decoder.py`, `archive.py`, `pipeline.py` і пояснити, що мережеве підключення ізольоване від правил декодування.

## 3. Запуск — 2 хвилини

Відтворюваний локальний варіант:

```bash
python main.py
```

На робочому комп’ютері з локальним `.env` онлайн-сценарій:

```bash
python main.py --source online --date ДД.ММ.РРРР
```

Не показувати вміст `.env`, логін або пароль під час демонстрації.

## 4. Raw-архів — 1 хвилина

Відкрити `archive/raw/рік/місяць/` і показати, що кожен ZRUR-файл має дату й тип у назві, а його текст не змінений декодером.

## 5. SQLite — 2 хвилини

Показати:

- `imports` — один рядок на початковий файл;
- `observations` — окремі рядки рівня, зміни, температури, опадів і витрати;
- `source_file` та `import_id` — мінімальний зв’язок із походженням.

Пояснити, що вечірній і ранковий рівні мають різні часові мітки й надалі утворять один часовий ряд для графіка.

## 6. Дублікати — 1 хвилина

Повторно виконати `python main.py`. Якщо декодер не змінився, у консолі з’явиться повідомлення «повторний файл — нових даних немає», а кількість імпортів і вимірювань не збільшиться. Після уточнення декодера той самий raw-файл можна повторно обробити: до архіву додадуться лише раніше відсутні параметри.

## 7. Тести та підсумок — 2 хвилини

```bash
python run_tests.py
```

Підсумок: 53 тести перевіряють старі групи, нові групи 0/4/8, варіант температури `4TT//`, часові мітки, онлайн-відповіді через mock, raw-структуру, міграцію SQLite та повний конвеєр.

Не заявляти, що вже готові GUI, бюлетені, розширений QC або автоматичні повторні мережеві спроби — це наступні етапи плану.
