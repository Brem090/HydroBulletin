# Демонстраційний набір тижня 3

Набір навмисно невеликий і синтетичний. Він показує один послідовний
оперативний цикл:

- імпорт рівнів за 11 і 12 липня 2026 року;
- перевірку `поточний рівень − учорашній рівень = добова зміна`;
- окремий імпорт добових SYNOP-опадів за інтервал 09:00–09:00;
- пріоритет опадів пов’язаної метеостанції над опадами з гідрологічного коду;
- один контрольний прапорець `INCONSISTENT_CHANGE` для поста 81244;
- коректне збереження від’ємного рівня для поста 81254.

Запуск у Windows: `run_week3_demo.bat`.

Запуск у консолі:

```text
python main.py --batch-folder demo_data/week3 --date 12.07.2026
```
